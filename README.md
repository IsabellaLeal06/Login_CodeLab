# 🌐 CodeLab Login

Tela de login moderna e responsiva desenvolvida com **HTML5** e **CSS3**, inspirada em interfaces minimalistas e focada em experiência do usuário.

---

## ✨ Preview

Interface dividida em duas seções:

- Área ilustrativa lateral
- Formulário de autenticação
- Login com Google
- Design clean e responsivo

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- Material Icons
